# GELIOS-7
ГЕЛИОС-7 Хардкорный хоррор о выживании на дне океана Глубина 10 994 метра Станция «Гелиос-7» — последний форпост человечества на дне Марианской впадины. Она была построена не для добычи ресурсов и не для научных открытий. Она была построена для прослушивания.  В 2039 году гидроакустики засекли сигнал со дна впадины. Он повторялся каждые 47 минут.
